Agent 最终回答

现象：宿舍 AP-DORM-02 信号强度良好（RSSI -56dBm），但实际下载速率仅 11 Mbps。  
工具：get_wifi_metrics 和 assess_wifi_link  
证据：信道忙碌率 89%，上联利用率 38%，客户端数 46，香农容量 398.69 Mbps  
可能原因：无线信道高度占用（89%）可能限制速率，上联链路负载中等  
结论：优先排查无线信道占用  
下一步：检查周边无线设备干扰及信道使用情况
